# FurryPattern CAD

面向兽装（Fursuit）花纹与纸样制作的本地桌面 CAD，将角色设定图、三维模型和二维裁片连接到同一套制作流程中。

从原图提取花纹，贴附到模型表面，沿颜色边界与自定义切线生成裁片，再检查拼接效果、设置缝份并导出实际尺寸纸样。

> 当前版本：`0.8.0`，内部开发预览。当前打包脚本面向 Windows x64，发布包尚未签名。主要编辑与制版流程在本地运行；AI 助手为可选功能，需要另行配置服务。

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 花纹提取 | 导入正背视图原图，提取颜色区域，进行真实尺寸标定；使用钢笔、套索、节点和曲线手柄修正轮廓与孔洞 |
| 模型管理 | 使用六种内置模板或导入 OBJ / GLB，调整尺寸、部位与网格，管理模型库 |
| 花纹映射 | 拖放贴附、按部位自动匹配、三维手绘，调整位置、宽高与角度，使用笔刷和节点编辑已贴附花纹 |
| 裁切版型 | 沿颜色边界和自定义切线裁切，支持对称与截面切线、展开检查和裁切版本库 |
| 拼接预览 | 按裁片的三维绑定重建拼接位置，逐片显示、分解查看，检查覆盖面积与缺失裁片 |
| 制版输出 | 编辑裁片、材料、毛向、缝份与剪口，排料，导出 SVG / DXF / PDF / PNG，支持 A3 / A4 实际尺寸分页 |
| 本地项目 | 项目库、撤销与重做、自动保存、恢复记录，以及 `.fpcad` 项目文件交换 |
| AI 助手 | 管理模型、提供商连接、技能和 Streamable HTTP MCP，可配置本地或远程模型服务 |

## 快速开始

### 使用已有发布包

如果已有完整发布目录，直接运行其中的 `FurryPatternCAD.exe`。分发时需要复制整个发布目录，不能只复制 EXE。

在当前项目工作目录中，也可以双击根目录的 **`启动新版FurryCAD.cmd`**。它读取 `release/latest.json`，启动该文件指向的程序，并使用 `.local/workspace` 作为工作库。

若提示发布包缺失，请按下方步骤从源码构建，或执行 `npm run package` 生成发布包。`release/` 是本地生成目录，不随源码提交；复制发布目录后可以直接运行其中的 EXE。

### 从源码运行

应用源码和构建配置直接位于仓库根目录。以下命令均在仓库根目录执行。

准备环境：

- Windows x64。
- Node.js，建议使用本地开发环境采用的 Node.js 24；项目指定 npm `11.13.0`。
- Rust `1.90.0`，以及 `rustfmt`、`clippy` 组件，版本由 `rust-toolchain.toml` 固定。
- Windows Rust 编译所需的 MSVC C++ 构建工具与 Windows SDK。

```powershell
# 进入仓库根目录，按实际位置调整
cd D:\Codex\furrycad

# 安装应用依赖
npm ci

# 先编译 Rust 几何工作进程，再构建桌面应用
npm run build:rust
npm run build

# 启动桌面应用
npm start
```

`npm start` 运行 `dist` 中已经构建的应用，不会自动构建，也不会读取发布包。修改前端或 TypeScript 代码后，可运行 `npm run dev` 重新构建并启动；修改 Rust 代码后需先执行 `npm run build:rust`。这里的 `dev` 是构建后启动，不是热更新服务。

构建脚本优先使用根目录 `.tools` 中已有的 Rust 工具链与离线依赖；没有这些本地资源时使用系统中的 Cargo。首次安装依赖通常需要网络。

## 使用流程

推荐顺序：**使用指南 → 花纹提取 → 模型管理 → 花纹映射 → 裁切版型 → 拼接预览 → 制版**。

### 1. 新建或打开项目

启动后，在项目首页选择已有项目，或点击“新建项目”并输入名称。已有 `.fpcad` 文件可通过“打开项目”载入。进入编辑器后，可先阅读“使用指南”；初次使用建议从简单模式开始，需要精细参数时切换到高级模式。

### 2. 导入原图并提取花纹

1. 在“花纹提取”中导入 PNG、JPEG 或 WebP 参考图，指定正背朝向和真实高度。
2. 精确制作时，用两点标定选取图中已知距离的两个端点，输入它们之间的实际距离，单位为毫米。
3. 提取颜色区域，在联合原图预览中核对轮廓、深色细节、孔洞和部位分类。
4. 遇到误识别、缺失线稿或遮挡时，用钢笔或套索修正选区，再点击“确认选区并加入花纹库”。
5. 核对花纹所属部位与左右侧；含糊区域需要手动分类，避免后续贴错位置。

图像像素不等于实际毫米。选区路径在确认前属于草稿，确认计算成功后才加入花纹库。

### 3. 创建或导入模型

在“模型管理”选择内置模板，或导入三角化的 OBJ / GLB 模型。检查身高、部位、比例和网格后再继续。

- OBJ 不自带单位：坐标以毫米表示时导入倍率用 `1`，以厘米表示时用 `10`。
- GLB 的米单位会自动转换为毫米，额外倍率通常保持 `1`。
- 导入后再次核对实际尺寸，确保与参考图标定一致。

### 4. 将花纹贴附到模型

在“花纹映射”把花纹库中的花纹拖到可见模型表面，或使用按部位自动匹配。自动匹配跳过的花纹会给出原因，可补充分类后重试或手动拖放。

旋转模型检查正面、背面和交界；根据需要调整花纹位置、宽高、角度，或通过三维手绘、加色与擦除笔刷、轮廓节点进行修正。自动位置与补全结果需要人工审阅，确认后再用于裁切。

### 5. 裁切并展开版型

在“裁切版型”选择部位，沿实际颜色边界裁切，并按需要使用钢笔、画笔、套索、对称或截面工具添加切线。

生成后检查展开失真、裁片边界和必要补缝，将可用结果保留到裁切版本库。如果随后修改了作为裁切依据的花纹边界，需要重新裁切，避免继续使用旧切缝。

### 6. 检查拼接预览

进入“拼接预览”，查看实际裁片还原到模型后的颜色和位置。使用逐片显示或分解视图检查缺口、覆盖范围、遗漏裁片与接缝，再进入制版。

此预览还原几何位置，不模拟布料张力或穿着效果。

### 7. 制版、导出与打印

1. 在“制版”从裁切库载入版型，核对裁片、材料、毛向、缝份、剪口与接缝。
2. 根据布幅与制作需求进行排料；修改源纸样后需要重新排料。
3. 处理几何或接缝检查提示，再导出 SVG、DXF、PDF 或 PNG；需要继续编辑或分享项目时保存 `.fpcad`。
4. 纸样打印选择 A3 / A4 分页，按页号和定位记号拼接。
5. 打印比例必须为 **100% / 实际大小**，不要选择“适合页面”；测量输出中的 **100 mm 校验尺**，确认比例后再制作。

## 常用操作

| 场景 | 操作 |
| --- | --- |
| 二维视图平移 | 中键拖动 |
| 三维模型旋转 | 中键拖动 |
| 三维模型平移 | `Shift` + 中键拖动 |

| 编辑 | 左键使用当前工具 |

## 文件与数据

- **开发运行与根目录启动脚本**：默认工作库位于 `.local/workspace`。
- **直接运行发布包**：默认使用应用用户数据目录，Windows 下通常为 `%APPDATA%\FurryPatternCAD`。
- **自定义数据目录**：可以通过环境变量 `FPCAD_DATA_DIR` 指定；根目录 `.cmd` 启动脚本会自行设置为上述开发工作库。
- **保存与迁移**：已提交操作自动保存到本地工作库；使用保存功能生成 `.fpcad` 文件，便于备份、迁移和交换。重新打开项目会清除未提交的交互草稿。

不要将 `.local/workspace` 当作测试缓存删除。`.tools` 用于本地工具链和离线依赖，也不应作为旧软件残留清理。

### 可选：配置 AI 助手

打开工具栏“AI 助手”，在助手的模型管理中配置提供商连接、服务地址及所需 API 密钥，再指定默认模型和连接。内置提供商配置包括 DeepSeek、Ollama、LM Studio、llama.cpp 和 vLLM；本地服务需要预先启动，远程服务需要有效凭据。还可管理技能与 Streamable HTTP MCP 连接。

## 开发与验证

桌面应用采用 **Electron + Vue 3 + TypeScript + Pinia**，使用 **Vite / esbuild** 构建；Rust 工作区提供几何核心与独立工作进程，本地项目库使用 SQLite。

在仓库根目录运行：

| 命令 | 用途 |
| --- | --- |
| `npm run build:rust` | 编译 Rust 工作进程，生成 release 构建 |
| `npm run build` | 构建桌面应用并复制 Rust 工作进程与资源 |
| `npm start` | 启动已构建应用 |
| `npm run dev` | 重新构建桌面应用后启动 |
| `npm run typecheck` | TypeScript / Vue 类型检查 |
| `npm test` | 运行 Vitest 测试 |
| `npm run test:rust` | 运行 Rust 工作区测试 |
| `npm run check` | 类型检查、Vitest 与 Rust 测试 |
| `npm run verify` | 类型检查、Vitest、Rust 测试、格式检查、Clippy 与应用构建 |
| `npm run test:desktop` | 运行桌面端测试套件 |
| `npm run package` | 构建 Rust 与桌面应用，生成 Windows 发布目录并更新 `release/latest.json` |

首次执行 `build` 或 `verify` 前，应先执行 `build:rust`，因为应用构建需要复制 Rust 可执行文件。`verify` 中的 Clippy 使用离线模式，需要已缓存或本地提供 Rust 依赖。

针对打包程序执行桌面测试：

```powershell
npm run package
$env:FPCAD_TEST_EXECUTABLE = (Get-Content release/latest.json -Raw | ConvertFrom-Json).executable
npm run test:desktop
```

更多专项测试见 [应用 package.json](package.json)。提交问题时建议附上复现步骤、版本、输入文件类型、预期与实际结果；提交改动前运行与改动范围相符的检查。

## 使用限制

- 当前为开发预览，自动提取、分类、贴附和遮挡补全需要人工核对；不可见区域无法从设定图唯一恢复。
- 设定图轮廓不直接等于可制作纸样，精确制作仍需真实尺寸标定、模型展开与试样验证。
- 旧项目中的花纹不会随升级自动重算；需要应用新的提取算法时，可使用“按当前标定重新拆分”，随后复核结果。
- 当前发布脚本仅实现 Windows 打包，其他平台尚无对应发布流程。

开发说明见 [项目结构](Docs/guides/project-structure.md)、[桌面架构](Docs/design/architecture.md)和[项目数据与契约](Docs/design/data-contracts.md)。第三方资源声明随发布包保存在 `THIRD_PARTY_NOTICES` 中。
