# 第三方插件与公共 SDK 规划

状态：未落地；整理日期 2026-10-26。[内置注册器](../../packages/modules/index.ts)有注册、依赖和生命周期逻辑，未接入当前主进程启动。助手技能文本和 MCP 清单也不等于插件系统。当前无第三方安装、隔离宿主、稳定公共 SDK 或商店。

## 先接内置模块

当前 `FeatureModule` 包含 ID、版本、能力、`initialize()`、`dispose()` 和显式依赖；初始化接口尚无上下文参数。先在应用启动验证排序、重复 ID、循环依赖、可选模块失败和释放订阅/工作线程，再根据需要设计受控上下文。注册器类或单元测试存在不能称为产品已经启用。

## 接口与隔离

第三方代码需独立进程或其他可验证的隔离宿主。只提供不可变项目快照及受控命令，不给数据库连接、主进程内存或任意文件系统。TypeScript 类型和使用约定不足以形成隔离。

候选清单含 ID/版本、应用/API 兼容范围、能力、权限、入口、哈希/签名和许可。权限区分项目读、命令写、用户选择文件及允许的网络地址；声明不等于授予，写入仍走修订和事务。

## 失败、卸载与兼容

API major 不兼容拒绝加载，用能力发现决定接口。超时/崩溃终止插件并放弃未提交事务，项目仍可保存。卸载移除程序，保留纸样和未知命名空间元数据，缺插件也能开项目。

实施前按[统一需求](requirements.md)定义安装/升级/卸载、权限变更、进程预算、迁移、回读及恢复验收。商店、签名信任和商业分发另立项；早期 I0/TC 编号只作追溯，不代表通过。
