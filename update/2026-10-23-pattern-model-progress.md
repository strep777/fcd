# 花纹、体型与制版修改记录

日期：2026-10-23。下列单元、组件与原生回归已完成，正式版验收已通过，最终桌面流程仍在复测。

## 修改内容

- 花纹边缘保留有图像证据的尖角，优先使用连续曲线。修正半圆退回像素台阶、模糊多色交界出现假转角的问题。
- 普通 RGB 边界定位与曲线拟合共用原始面积预算，避免两步误差叠加造成小花纹收缩；经图像证实的尖角仍采用其测量边界。小区域先细化相邻曲线，再考虑回退。
- 耳部黄色长斜边不再逐个拟合栅格台阶；仅连接经原图误差校验的短端段，保留交汇点。真实 JPEG 回归同时检查长边连续性和尖角，计算预算修正另通过 77 项复测。
- 花纹修改页提供独立的增加选区、减少选区画笔，支持草稿撤销、重做与保存。
- DTD 按穿戴者尺寸生成；一体填充在其基础上增加髋部、大腿和小腿体积。两种模式独立保存、切换，DTD 不应用填充厚度。
- 新拖入花纹沿曲面局部坐标贴附。粗网格和曲线远端均纳入完整计算；孔洞、尺寸和移动后的轮廓保留。超出有效曲面的操作拒绝保存，不再悄悄提交截断结果。
- 粗模型面上的高采样花纹使用精确分区满足保存预算，不丢弃花纹，也不在投影视图中简化后放大曲面误差。
- 窄花纹的变换手柄按投影大小缩小命中范围，保留中间的移动区域，并选择最近的手柄。修复缩小花纹后拖动被误判为缩放的问题。
- Tauri 的 JSON 解析启用精确浮点往返，避免无改动确认也改变坐标的最低有效位，保留轮廓与依赖指纹的一致性。
- 取消计算按本次请求 ID 关联。即使取消消息先于 mask 请求到达后端，后续任务也会被取消；同一修订的新请求可以重试。全局拼接间距更新使用同一链路；普通编辑不受影响。显式空目标不取消其他任务，旧无目标接口继续取消已登记的匹配任务。
- 模板先建立肩、腕、髋、踝等结构裁线，后续补线使用穿过三角形内部的截面。改善展开与校缝求解，拒绝产生微小孤片的截面，并拆开近乎断开的裁片连接，再尝试并入合适邻片。
- 制版默认选择并显示全部裁片，用户主动取消的选择不被重置。
- 模型来源对话框支持 Tab、Shift+Tab 和 Escape；关闭后恢复原按钮焦点，防止键盘操作落入背景页面。
- 统一使用“拼接间距”和“拼接间距大小”。修改后直接更新全部当前裁片，重算导出轮廓，清除旧边级覆盖并使旧排料失效；历史快照不改写。

## 适用范围

模型是可调整的制作基体，参考作品用于理解一体填充外形，不替代用户实测尺寸或材料试做。旧项目中没有曲面包覆标记的花纹保留原有投影数据，不在打开项目时擅自改动。无法通过几何校验的截面仍可能使用局部网格分区回退；本轮不宣称达到 CLO3D 的全部制版能力。

研究参考：[WikiFur DTD](https://zh.wikifur.com/wiki/%E5%85%BD%E8%A3%85DTD)、[万物通行作品库](https://www.ww-pass.com/gallery/works/)。
