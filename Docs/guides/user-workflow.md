# 从设定图到制作纸样

适用版本：0.8.0 工作区，整理日期 2026-10-26。操作来自当前源码，本文没有代替运行验收。完整能力见[功能清单](feature-catalog.md)，效果与验收要求见[需求与验收](../planning/requirements.md)。

## 新建项目

在首页选择本地项目，或新建一个有名称的项目。已有 `.fpcad` 文件用顶部“打开”载入。已提交操作写入本地项目库；“保存”和“另存为”生成可备份、交换的文件。删除首页项目不会删除单独保存的文件，但会永久删除软件内该项目的历史和恢复记录。

首次可保持简单模式。左侧顺序是“使用指南 → 花纹提取 → 花纹修改 → 模型管理 → 花纹映射 → 裁切版型 → 拼接预览 → 制版”。可返回修改，后续绑定是否有效由检查结果决定。高级模式增加求解、材料、接缝、排料和精细编辑入口；切回简单模式会返回版型预览。

## 上传并标定整张图

“上传设定图并提取花纹”导入 PNG、JPEG 或 WebP 后开始提取。要先自己标定，选“仅导入设定图”。原图保留完整画面，无需预先拆正背面。

选“两点标定”，在同一角色上点已知距离的两个端点，输入毫米并保存。例如 10 cm 输入 100。像素数量不能直接当纸样毫米。新标定更新来源尺寸并移除旧贴附；锁定贴附会阻止更新。

用“按当前标定重新提取”应用新尺寸。重新提取替换来源及相关贴附，完成后核对身体色块、深色细节、孔洞和遮挡边界；部位与左右侧按角色自身判断。缝制色块设为“缝制色块”，瞳孔、高光等可设“印绘／贴花细节”，后者保留图形但不单独裁成缝制片。

## 修正来源花纹

漏选或误选时，在原图使用颜色选取、钢笔或套索。钢笔闭合至少三个节点，闭合后仍可拖动。点击“确认选区并加入花纹库”或“确认颜色选区并加入花纹库”，计算成功便保存，不需再接受一次。若遇到旧项目或接口留下的独立候选，检查后点“接受到花纹库”。高级模式可减去路径形成孔洞、载入已有来源或生成参考补全；推断路径须核对后确认。

在花纹库搜索、分类、改名、调颜色或制作方式。含糊区域可保留待分类，避免强行贴错部位。库支持多选删除，同时移除当前及非活动模型中的关联贴附和派生推断；锁定关联会阻止整批删除。成功删除可撤销，裁切历史保留。

在“花纹修改”的独立画布对照原图补画、擦除或钢笔修补。默认虚线显示选区，需要时开启节点微调。修改先留草稿，保存才更新来源；失败会保留草稿并解释原因。切换花纹或离开页面时选择保存、放弃或返回编辑。

## 准备毫米模型

生成内置模板，或导入三角化 OBJ/GLB。OBJ 无单位，毫米坐标倍率用 1、厘米用 10。GLB 米先转毫米，额外倍率通常用 1。导入后核对实际尺寸。

模板有 DTD 人体基体、一体填充外形和兽装外形。DTD 表示穿戴者；一体填充是打版衣身，领口、袖口和脚踝口敞开，其模型高度不同于穿戴者身高；兽装外形提供物种及附肢参数。输入测量与生成后的实测报告分开解释。

导入和生成自动入模型库，切换时恢复模型自己的花纹与裁片。通用模型可指定身体、头、手爪或脚等类型，再逐组修正部位和自身左右侧；特殊姿势须人工核对。

选择整个对象、部位或顶点后，可拖动或输入移动、旋转、缩放。整体变换携带花纹，局部编辑使旧投影失效。内置模型可按身体约束拟合，或自由缩放包围框；自由缩放后原身体配方报告不再适用。变更后检查花纹并重新裁切。

自定义 `.fpctemplate`/JSON、Morph 和雕刻见功能清单 F13；它们依赖声明的测量和权重，不能替代试穿。

## 贴附并审阅模型

从抽屉拖动来源到可见模型，或按所选部位自动贴附。检查已贴附数量和跳过原因；缺失部位、未知侧别应分类后重试或手工贴附。

选中花纹后拖动变换手柄，或输入宽高、角度。`Ctrl+T` 进入自由变换，`Shift` 约束比例或旋转步长，`Enter` 确认、`Esc` 取消。旋转检查正背面、侧面、尾部和色块交界，再确认自动位置。

画笔可直接补画，设置颜色、毫米半径和形状，松开保存一笔。对称绘画两侧同次保存和撤销，模型不满足对应条件时需手画。节点工具可调轮廓/孔洞，确认前可取消。

“在模型上补全侧面花纹”会启用画笔并标出未贴附面，供手工补画。邻面延伸和精确对称推断已有请求/组件实现，但当前页面没有挂载其工具；已有或经接口生成的推断可在贴附记录中逐条审阅。检查完整模型后可一次确认并锁定全部贴附，编辑前先解锁；清空当前贴附保留源库和裁切历史。

已有裁片可编辑片内花纹、协调编辑来源节点或从 UV 纹理选色。跨接缝变化应改来源，片内修改不能随意改变接缝交点。纹理使用代理分割，细节须复核。

## 绘裁线并确认候选

在“裁切版型”选择绘制部位，它只限制手绘裁线，不缩小自动计算范围。用曲面钢笔画闭合裁线，至少三个节点；开放结构缝或省道至少两个节点。中键旋转、`Shift` 加中键平移可换面继续。保存后可启用、改名、聚焦和编辑；草稿先保存或取消才能计算。分区选择模式还能将所选面组成片区，或锁定其边界为切缝。

设置 0–10 cm 拼接间距，0 表示不加。应用更新全部当前片，历史快照保留原值。颜色拆分开关决定是否沿缝制色块分片；高级模式另有半侧/中线和展开参数。

点击“自动计算裁线并预览”。模型半透明边界和二维窗口显示候选，可切到映射页检查再返回。计算工作量中的网格数不是最终片数，二维窗口中的“片”才是候选数量。

检查轮廓、孔洞、覆盖、补缝和失真。必要补缝会增加接缝；数值检查通过不等于适合制作。超阈值失真须审阅，改过间距须重算。确认可用后点“确认版型并保存到裁切库”，候选才变成当前制作片。

任务可请求取消，等后台退出后重试。超时保留原项目，可缩小范围、补线或调整设置再算。

## 检查实际裁片拼接

“拼接预览”可选当前候选、当前制作片或历史版，逐片显示、选择和分解。缺片留下缺口，失效片隐藏并提示重算；原模型不能代替缺失裁片。

预览只重建保存位置，不计算布料张力、缝合变形或穿着。确认覆盖和接缝后进入制版。载入裁切库旧版会恢复其模型、花纹及片，可撤销；编辑当前片不改库中历史。

## 制版和输出

简单模式提供预览和裁片列表，可勾选片、看总览/单片、移动、旋转、测量及选纸张背景。屏幕缩放和平移不改毫米尺寸。

| 高级工具 | 应检查的结果 |
| --- | --- |
| 裁片编辑 | 名称、宽高、数量、镜像、毛向/布向、曲线、孔洞、标签/剪口；轮廓变更后检查失效绑定 |
| 拼接间距 | 统一应用替换逐边差异；逐边先算候选，来源变动应重算 |
| 材料 | 保存版本并关联片；毛长/弹性为记录，补偿须在模板显式采用 |
| 接缝 | 按缝线配对，核对长度、吃量、公差；有效时生成配对剪口 |
| 排料 | 按材料、布幅、片距及毛向计算，查漏件；源片变动须重排；不利用孔洞嵌套 |
| 制作流程 | 节点备注和完成状态供记录；JSON/ZIP 用于交换，不替代制造检查 |

裁片默认全选。简单模式主要作用于勾选批次；高级模式同时有当前单片和批次操作。分页预览可看拼接总图、单页和页号，选页后打印或导出 PDF。顶部整单导出支持 SVG、PDF、144 DPI PNG 和毫米 DXF，可选择有效排料。

数量表示总份数；开启镜像后，第 2、4……份镜像，不会再翻倍。例如数量 2 加镜像输出原片与镜像各一份。左右、正反面、拉链／省道说明和具体实例配对应在片名、文字或随附说明中写清；制作流备注不会自动排到纸上。当前导出只画一个有效方向箭头，毛向与布向的处理及整套核对步骤见[版片交付规格](pattern-delivery.md)。

错误阻止制造输出，警告须检查后确认。修订/纸张变动关闭旧预览，应重新生成。打印选 **100% / 实际大小**，关闭“适合页面”，先测 **100 mm 校验尺**。画布纸张背景是参照，分页预览显示实际拼接位置。

## 失败、撤销和恢复

“检查与记录”显示问题、逐边任务、提交历史和恢复点，点问题进入对应对象。关闭错误横幅不会修复问题。

撤销/重做协调草稿与提交历史。待采用计算结果只有来源仍有效才能写入；绘图保存失败通常保留草稿。项目切换或重开不保留未提交交互草稿。首页永久删除不可撤销，需要保留的项目先另存文件；不要把用户库当缓存清理。

## 助手边界

助手页管理提供商、模型、默认连接、技能文本和 Streamable HTTP MCP。测试只获取模型清单或工具名称，保存技能不执行命令。当前没有内置聊天或自主工具执行；添加模型不等于软件已能用它识别设定图。

外部本机助手可在启用连接后，使用界面地址和本次启动令牌调用允许的 CAD 请求，仍受修订及结果检查约束。关闭开关会停止监听并拒绝未执行的请求，已经开始的 CAD 操作仍可能完成。ONNX、云同步、商业授权和插件宿主见[后续规划](../planning/roadmap.md)。
