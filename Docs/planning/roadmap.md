# 后续功能规划

此目录保留尚未落地的设计，供后续评估和实施使用。具体排期、产品范围、商业规则和验收指标尚未确定；文档中的目标不代表已实现、已验证或已获商业批准。

## 已有能力与待实现部分

| 主题 | 当前已有 | 待实现规划 |
| --- | --- | --- |
| [本地 AI](local-ai.md) | 提供商连接、模型列表、技能与 MCP 管理；传统提取和手工修正 | ONNX 本地分割、分类、关键点、模型制品校验与评估数据治理 |
| [授权管理](licensing.md) | 本地项目与 CAD 工作流 | 账号、能力授权、离线签名令牌、订阅与配额 |
| [可选云服务](cloud-services.md) | 本地文件保存与交换 | 授权和更新服务、模型目录，以及后续的团队、SSO 与项目同步 |
| [插件与 SDK](plugin-sdk.md) | 内置模块注册、依赖检查与生命周期管理 | 隔离的第三方插件宿主、权限模型、稳定公共 API 和插件商店 |

## 其他后续方向

早期规划还包含真实布料/缝合模拟、多视图 AI 重建、模板市场、机器控制、企业私有服务，以及 Windows 之外的平台发布。这些方向需要独立确定需求、依赖、评估样本和交付边界，不计入当前桌面预览的已实现能力。

## 实施前需要明确

- 需求范围、输入输出契约、兼容与迁移策略。
- 可验证的验收样本、性能目标和故障回退方式。
- 模型与数据许可、离线可用性、凭据和权限边界。
- 负责人、依赖关系和实际排期；旧增量编号与工期估算不作为当前承诺。

规划文件保留早期的 I8/I9、TC 等设计编号供追溯，不将其视为现行任务或测试已经完成。现行架构见[桌面应用架构](../design/architecture.md)，数据契约见[项目数据与契约](../design/data-contracts.md)。
