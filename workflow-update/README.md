# FurryPattern CAD

当前维护目录为 `workflow-update`。导航顺序：**使用指南 → 花纹提取 → 模型管理 → 花纹映射 → 裁切版型 → 拼接预览 → 制版**。本版本仍为离线开发预览。最新非花纹功能检查、修复及测试边界见 [功能验收记录](Docs/最新功能验收/audit.json)。

## 启动

双击父目录的 `启动新版FurryCAD.cmd`，或在本目录运行 `npm start`。开发启动默认使用本目录 `.local/workspace`，已有项目保存在这里；不要当作测试数据删除。根目录 npm 命令已统一转发到当前维护目录。启动脚本读取最新发布包。

可分发程序位置由 `release/latest.json` 指定。复制整个对应发布目录，不能只复制 EXE。发布包默认使用应用自己的用户数据目录；通过“打开项目”载入 `.fpcad`。源码目录不是发布包。

每次启动先显示项目首页，选择已有项目、新建或打开文件后进入编辑器。二维视图中键平移，模型中键旋转、Shift＋中键平移，滚轮缩放；左键使用当前编辑工具。简单模式保留日常操作，高级模式展开精细参数。

## 工作流程

- **使用指南**：各步骤、参数含义及操作方法。
- **花纹提取**：原图联合预览、颜色区域提取、像素约束的直边与曲边恢复、阴影近似合并、标定、钢笔与可编辑选区。选区在确认后计算并自动加入花纹库；花纹详情支持节点、Bézier 手柄、笔刷和钢笔修补并同步原图；自动分类存在歧义时需要手动确认。
- **模型管理**：重新建模的六种内置模板、连续曲面、OBJ/GLB 导入、模型库、尺寸与网格编辑。
- **花纹映射**：拖拽到可见模型表面直接贴附、自动匹配、三维手绘、已贴附花纹拖动及宽高／角度调整、加色／擦除笔刷、外轮廓与孔洞节点编辑、补全审阅与锁定。自动匹配会报告跳过原因。
- **裁切版型**：部位选择、钢笔/画笔/套索、对称与截面切线；默认以实际颜色边界和裁切线形成裁片，仅为展开和缝份有效性增加必要接缝，保留裁切版本库。
- **拼接预览**：从实际裁片的三维绑定重建模型、逐片显示、分解查看、覆盖面积和缺失裁片检查；位于制版之前。此视图还原几何位置，不模拟布料张力。
- **制版**：从裁切库载入版型、裁片编辑、缝份与剪口、全部选中裁片的自适应总览、单片 A3/A4 实际尺寸分页、排料、制作流程、SVG/DXF/PDF/项目交换。

工具栏“AI 助手”提供模型、技能和 Streamable HTTP MCP 管理。在模型管理中关联和编辑提供商连接，同一个模型可使用多个连接，并可指定默认模型与连接。默认包含 DeepSeek、Ollama、LM Studio、llama.cpp、vLLM；连接实际服务需要对应服务已启动或有效 API 密钥。

几何单位为 mm。缩放预览不改变导出尺寸。打印使用 100% 实际尺寸，并测量 100 mm 校验线。重开项目会清除未提交的交互草稿，已提交数据自动保存。缺失或遮挡部分的补全是待审阅推断，不能保证唯一恢复真实花纹。

自动双视图、钢笔 mask 和按颜色选取使用原图。兼容接口中的 Lab/HSV 聚类仍采用 512 像素代理，已从日常操作区移出。已有旧花纹不会随升级自动重算；点击“按当前标定重新拆分”应用新版边缘、深色细节和分类，可撤销。连续同色区域保持原始轮廓，分类参考不会在原图上切出直线。

## 开发与验证

```powershell
npm ci
npm run build:rust
npm run verify
npm run test:build
$env:FPCAD_TEST_EXECUTABLE=(Get-Content release/latest.json -Raw | ConvertFrom-Json).executable
npm run test:desktop
```

`test:build` 检查旧资源清除和重复打包，并产生发布目录。桌面套件包含独立的首次启动检查，全部使用隔离数据和隐藏窗口。可用 `npm run test:desktop -- --jobs 3` 并行运行，依赖前置样本的套件会等待样本生成。仅在受限测试环境确有需要时设置 `FPCAD_TEST_NO_SANDBOX=1`；这不修改生产沙箱。Rust 工具和离线依赖可使用本目录或父目录 `.tools`。父目录 `.tools` 提供当前 Rust 工具链和离线依赖，需要保留。

最新审计摘要、测试明细和界面对照保留在 `Docs/最新功能验收`。记录区分发布包端到端测试和隔离生产组件测试；外部 AI 服务使用本地模拟服务，打印验证不发送实体打印作业。临时测试项目和中间输出在 `test-results`、`.local/tests` 和文档 `evidence`，历史验收数据由 Git 保存。

## 清理

关闭测试进程后，用 PowerShell 7 执行：

```powershell
./scripts/clear-test-data.ps1 -WhatIf
./scripts/clear-test-data.ps1
```

默认只删除生成的测试目录、下载缓存和测试输出，保留真实工作库、测试程序、固定回归样本、生产资源、发布包和最终审计。程序运行或目录包含链接时拒绝清理。历史文档中的截图路径和旧统计仅代表当时记录，以最新审计为准。
