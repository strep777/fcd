# FurryPattern CAD

面向兽装（Fursuit）花纹与纸样制作的本地桌面 CAD，将角色设定图、三维模型和二维裁片连接到同一套制作流程中。

从原图提取花纹，贴附到模型表面，沿颜色边界与自定义切线生成裁片，再检查拼接效果、设置拼接间距并导出实际尺寸纸样。

> 当前版本：`0.8.0`，内部开发预览。当前打包脚本面向 Windows x64，发布包尚未签名。主要编辑与制版流程在本地运行；AI 助手为可选功能，需要另行配置服务。

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 花纹提取 | 导入正背视图原图，提取颜色区域，进行真实尺寸标定；使用钢笔、套索、节点和曲线手柄修正轮廓与孔洞 |
| 模型管理 | 按穿戴者尺寸生成 DTD 与一体填充模型并分别保存，也可使用物种模板或导入 OBJ / GLB，支持对象、部位、顶点变换 |
| 花纹映射 | 拖放贴附、按部位自动匹配、模型表面自由填色；自由变换中可连续缩放、旋转和移动，确认后一次保存；设置笔刷大小、圆形或方形，在实际曲面边缘调整轮廓节点 |
| 裁切版型 | 沿颜色边界和自定义切线裁切，支持对称裁线、0–10 cm 拼接间距、二维点击联动三维位置、计算进度和裁切版本库 |
| 拼接预览 | 左侧按三维绑定重建模型，右侧按轮廓选择裁片；逐片显示、分解查看并检查覆盖 |
| 制版输出 | 编辑裁片、材料、毛向、拼接间距与剪口，在裁片中间显示毛向／布纹方向，排料，导出 SVG / DXF / PDF / PNG，支持 A3 / A4 实际尺寸分页 |
| 本地项目 | 项目库、撤销与重做、自动保存、恢复记录，以及 `.fpcad` 项目文件交换 |
| AI 助手 | 管理模型、提供商连接、技能和 Streamable HTTP MCP，可配置本地或远程模型服务 |

## 快速开始

### 使用已有发布包

如果已有完整发布目录，直接运行其中的 `FurryPatternCAD.exe`。分发时需要复制整个发布目录，不能只复制 EXE。

在当前项目工作目录中，也可以双击根目录的 **`启动新版FurryCAD.bat`**。它在缺少依赖时自动执行 `npm ci`，每次编译 Rust 工作进程、构建并启动当前源码，使用 `.local/workspace` 作为工作库。首次启动需要网络及下方列出的构建环境；失败时窗口会保留错误信息。

若需要生成独立发布包，执行 `npm run package`。便携包输出到 `release/` 并更新 `release/latest.json`。如需 NSIS 安装程序，运行 `npm run package:installer`，输出位于 `apps/desktop/src-tauri/target/release/bundle/nsis/`。这些生成目录不随源码提交。

### 从源码运行

应用源码和构建配置直接位于仓库根目录。以下命令均在仓库根目录执行。

准备环境：

- Windows x64。
- Node.js，建议使用本地开发环境采用的 Node.js 24；项目指定 npm `11.13.0`。
- Rust `1.90.0`，以及 `rustfmt`、`clippy` 组件，版本由 `rust-toolchain.toml` 固定。
- Windows Rust 编译所需的 MSVC C++ 构建工具与 Windows SDK、WebView2 Runtime。

```powershell
# 进入仓库根目录，按实际位置调整
cd D:\Codex\furrycad

# 安装应用依赖
npm ci

# 先编译 Rust 几何工作进程，再构建桌面应用
npm run build:rust
npm run build

# 启动桌面应用
npm start
```

`npm start` 运行 `apps/desktop/src-tauri/target/release/FurryPatternCAD.exe`，不会自动构建，也不会读取发布包。修改前端或 TypeScript 代码后，可运行 `npm run dev` 重新构建并启动；修改 Rust 代码后需先执行 `npm run build:rust`。这里的 `dev` 是构建后启动，不是热更新服务。

启动器输出与后台错误保存在 `test-results/startup/launcher.log`（每次启动覆盖）。若构建完成后没有出现窗口，可查看该日志中的启动路径和错误信息；双击启动脚本遇到异常退出时会保留窗口。BAT 会转发启动参数，例如后台验证使用 `--fpcad-background-test`。

构建脚本优先使用根目录 `.tools` 中已有的 Rust 工具链与离线依赖；没有这些本地资源时使用系统中的 Cargo。首次安装依赖通常需要网络。

## 使用流程

推荐顺序：**使用指南 → 花纹提取 → 花纹修改 → 模型管理 → 花纹映射 → 裁切版型 → 拼接预览 → 制版**。

已保存项目会保留原先的花纹轮廓。要使用当前边缘提取算法，请重新执行原图提取，并在检查贴附位置后重新裁切。

模型管理中先选择对象、部位或顶点，再使用移动、旋转、缩放工具拖动，或输入毫米、角度和缩放倍率。Shift 点击可增减选择，轴约束可限制拖动方向。整体变换会携带贴附花纹；局部网格编辑会使旧投影失效，需要重新贴附并计算裁片。

裁切前可设置 0–10 cm 拼接间距；0 表示不添加。候选按颜色边界和保存的裁线生成，曲面需要时补充展开切缝。点击二维候选可在模型上查看准确区域，裁片中心箭头标示毛向或布纹方向。修改“拼接间距大小”后，全部当前裁片直接更新，无需采用计算候选；历史裁切快照保留原设置。

### 1. 新建或打开项目

界面采用浅色桌面工作区：左侧选择制作阶段，顶部管理项目与撤销操作，当前工具和属性显示在画布旁。分栏边界可拖动调整；较窄窗口会把阶段导航移到顶部。AI 助手连接入口位于阶段导航末尾。

启动后，在项目首页选择已有项目，或点击“新建项目”并输入名称。已有 `.fpcad` 文件可通过“打开项目”载入。进入编辑器后，可先阅读“使用指南”；初次使用建议从简单模式开始，需要精细参数时切换到高级模式。

导入、另存为和导出会先等待你选完文件或保存位置，再显示后台处理进度。等待选择时不显示加载动画；很快完成的操作也不会闪出进度提示。选择期间会防止重复提交，取消后可以重新操作。导出需要选择项目保存位置和输出位置时，取消任一步都不会触发本次文件写入。

### 2. 导入原图并提取花纹

1. 在“花纹提取”中导入 PNG、JPEG 或 WebP 参考图，核对识别的正背朝向。
2. 精确制作时，用两点标定选取图中已知距离的两个端点，输入它们之间的实际距离，单位为毫米。
3. 提取颜色区域，在联合原图预览中核对轮廓、深色细节、孔洞和部位分类。
4. 遇到误识别、缺失线稿或遮挡时，用钢笔或套索修正选区，再点击“确认选区并加入花纹库”。
5. 核对花纹所属部位与左右侧；含糊区域需要手动分类，避免后续贴错位置。

图像像素不等于实际毫米。选区路径在确认前属于草稿，确认计算成功后才加入花纹库。

轮廓恢复依据原图边缘保留直线、尖角和真实曲线。高级模式的“自定义曲线拟合”同样受原图像素边界约束；毫米容差过紧或计算预算不足时保留原始轮廓，不会为减少节点而把直边圆滑化。

在“花纹修改”页选择花纹，可在大画布中对照原图补画或擦除。默认显示黑白虚线选区，不显示密集节点；需要逐点调整时启用“节点微调（高级）”。修改支持撤销、重做，点击“保存花纹修改”更新原花纹。切换页面或花纹前会提示处理未保存的修改。

### 3. 创建或导入模型

在“模型管理”选择内置模板，或导入三角化的 OBJ / GLB 模型。检查身高、部位、比例和网格后再继续。

- OBJ 不自带单位：坐标以毫米表示时导入倍率用 `1`，以厘米表示时用 `10`。
- GLB 的米单位会自动转换为毫米，额外倍率通常保持 `1`。
- 导入后再次核对实际尺寸，确保与参考图标定一致。

### 4. 将花纹贴附到模型

在“花纹映射”把花纹库中的花纹拖到可见模型表面，或使用按部位自动匹配。自动匹配跳过的花纹会给出原因，可补充分类后重试或手动拖放。

旋转模型检查正面、背面和交界。选中花纹后会直接显示变换手柄：拖动方形手柄缩放，拖动圆形手柄旋转，`Ctrl+T` 也可进入变换；按住 `Shift` 可等比缩放或按 15° 旋转，`Enter` 确认，`Esc` 取消。左侧宽高与角度随拖动更新，也可以输入数值后应用。视角导航位于模型工作区右上角。

点击笔刷即可直接在模型上填色，无需预先选择花纹；可设置毫米半径、圆形或方形和颜色。松开后保存一笔，并在毫米误差范围内将笔迹外轮廓拟合为较少的可编辑节点。选中花纹后点击节点工具调整轮廓。对称绘制会显示模型对称轴，将新笔迹同时贴附到另一侧；两侧作为同一次操作保存和撤销。模型两侧不对应时可能无法贴附，请检查结果。

旧项目中直接在模型上绘制的密集轮廓，进入节点编辑时也会按相同容差生成精简草稿；裁切保存或从裁片库恢复后仍可使用。确认后才保存；取消编辑保留原笔迹，已有曲线控制点保持不变。

需要补画侧面时，点击模型工具栏的“在模型上补全侧面花纹”，转动模型并直接填色。检查贴附与手绘结果，确认后再用于裁切。

### 5. 裁切并展开版型

“裁切版型”左侧管理绘制部件、已保存裁线和展开设置，中间显示模型，右下角的二维预览可收起或放大。用户裁线只用钢笔绘制，默认闭合；至少需要三个不同节点。未闭合、分叉或重走的路径不能保存，需修改后重试。保存会逐段核对实际切缝与绘制预览，防止保存后路径改变。“花纹画笔（涂区域）”用于补画和擦除材料区域，松开后保存花纹并生成精简轮廓节点；它不会把每个鼠标落点变成裁线节点。中键旋转、`Shift` + 中键平移及视角按钮都保留当前裁线草稿，可转到另一面继续绘制和闭合。新裁线按三维落点沿曲面连接；旧项目的平面投影裁线继续使用原规则。

点击“自动计算裁线并预览”，程序根据颜色边界、自定义裁线和必要补缝计算 UV 展开候选。候选的实际裁片边界以 50% 不透明度显示在模型上，可在右上角“显示”中开关；切到花纹映射页仍可查看。确认保存后，映射页显示当前有效裁片的边界；二维窗口显示毫米纸样。计算过程中显示动画、阶段、展开面数和运行时间，可随时取消；取消后等待后台退出，完成状态会在界面提示。普通裁切最多运行 60 秒；复杂颜色边界任务根据贴附规模增加计算时间，最长 15 分钟，可随时取消。超时会终止后台计算，保留原项目，不会保存未完成的候选。可缩小本次制版范围或补充裁线后重试。检查接缝及失真后再确认保存。旧项目已保存的裁线仍保留，可进入钢笔编辑修复；启用的开放裁线必须修复闭合或禁用后才能展开。

在二维预览中选择裁片后，视图聚焦该片；选择“全部裁片”返回总览。缩放和平移只改变屏幕显示，不改变纸样毫米尺寸或导出比例。

生成后检查展开失真、裁片边界和必要补缝，将可用结果保留到裁切版本库。如果随后修改了作为裁切依据的花纹边界，需要重新裁切，避免继续使用旧切缝。

### 6. 检查拼接预览

进入“拼接预览”，查看实际裁片还原到模型后的颜色和位置。使用逐片显示或分解视图检查缺口、覆盖范围、遗漏裁片与接缝，再进入制版。

此预览还原几何位置，不模拟布料张力或穿着效果。

### 7. 制版、导出与打印

1. 在“制版”从裁切库载入版型，核对裁片、材料、毛向、拼接间距、剪口与接缝。
2. 根据布幅与制作需求进行排料；修改源纸样后需要重新排料。
3. 处理几何或接缝检查提示，再导出 SVG、DXF、PDF 或 PNG；需要继续编辑或分享项目时保存 `.fpcad`。
4. 纸样打印选择 A3 / A4 分页，按页号和定位记号拼接。
5. 打印比例必须为 **100% / 实际大小**，不要选择“适合页面”；测量输出中的 **100 mm 校验尺**，确认比例后再制作。

## 文件与数据

- **开发运行与根目录启动脚本**：默认工作库位于 `.local/workspace`。
- **直接运行发布包**：默认使用应用用户数据目录，Windows 下通常为 `%APPDATA%\FurryPatternCAD`。
- **自定义数据目录**：可以通过环境变量 `FPCAD_DATA_DIR` 指定；根目录 `.bat` 启动脚本会自行设置为上述开发工作库。
- **保存与迁移**：已提交操作自动保存到本地工作库；使用保存功能生成 `.fpcad` 文件，便于备份、迁移和交换。重新打开项目会清除未提交的交互草稿。

不要将 `.local/workspace` 当作测试缓存删除。`.tools` 用于本地工具链和离线依赖，也不应作为旧软件残留清理。

### 可选：配置 AI 助手

打开工具栏“AI 助手”，在助手的模型管理中配置提供商连接、服务地址及所需 API 密钥，再指定默认模型和连接。内置提供商配置包括 DeepSeek、Ollama、LM Studio、llama.cpp 和 vLLM；本地服务需要预先启动，远程服务需要有效凭据。还可管理技能与 Streamable HTTP MCP 连接。

## 开发与验证

桌面应用采用 **[Tauri v2](https://v2.tauri.org.cn/) + Vue 3 + TypeScript + Pinia**，界面使用 **WebView2**，通过 **Vite / esbuild / Tauri CLI** 构建；Node.js 独立后台保留数据库事务与工作线程；Rust 工作区提供几何核心与独立工作进程，本地项目库使用 SQLite。

在仓库根目录运行：

| 命令 | 用途 |
| --- | --- |
| `npm run build:rust` | 编译 Rust 工作进程，生成 release 构建 |
| `npm run build` | 构建桌面应用并复制 Rust 工作进程与资源 |
| `npm start` | 启动已构建应用 |
| `npm run dev` | 重新构建桌面应用后启动 |
| `npm run typecheck` | TypeScript / Vue 类型检查 |
| `npm test` | 运行 Vitest 测试 |
| `npm run test:rust` | 运行 Rust 工作区测试 |
| `npm run check` | 类型检查、Vitest 与 Rust 测试 |
| `npm run verify` | 类型检查、Vitest、Rust 测试、格式检查、Clippy 与应用构建 |
| `npm run test:desktop` | 运行桌面端测试套件 |
| `npm run package` | 构建 Rust 与 Tauri 桌面应用，生成 Windows 便携包并更新 latest 指针 |

首次执行 `build` 或 `verify` 前，应先执行 `build:rust`，因为应用构建需要复制 Rust 可执行文件。`verify` 中的 Clippy 使用离线模式，需要已缓存或本地提供 Rust 依赖。

针对打包程序执行桌面测试：

```powershell
npm run package
$env:FPCAD_TEST_EXECUTABLE = (Get-Content release/latest.json -Raw | ConvertFrom-Json).executable
npm run test:desktop
```

更多专项测试见 [应用 package.json](package.json)。提交问题时建议附上复现步骤、版本、输入文件类型、预期与实际结果；提交改动前运行与改动范围相符的检查。

```text
├── release/                    # Windows 发布包（生成）
└── .local/workspace/           # 本地用户工作库（运行时生成）
```

## 使用限制

- 当前为开发预览，自动提取、分类、贴附和遮挡补全需要人工核对；不可见区域无法从设定图唯一恢复。
- 自动补缝的形状和裁片数量仍在验证，部分模型会出现沿网格的锯齿接缝或较多小片。通过失真与覆盖检查不代表裁线已经适合制作，也不保证裁片数量最少。
- 设定图轮廓不直接等于可制作纸样，精确制作仍需真实尺寸标定、模型展开与试样验证。
- 旧项目中的花纹不会随升级自动重算；需要应用新的提取算法时，可使用“按当前标定重新拆分”，随后复核结果。
- 当前发布脚本仅实现 Windows 打包，其他平台尚无对应发布流程。
