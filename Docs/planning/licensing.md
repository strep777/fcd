# 账号与能力授权备选方案

状态：未实现，不属于当前自用离线软件的既定需求。整理日期：2026-10-26。当前无订阅、商业令牌、配额或收费门禁；高级模式、DXF、排料等现有功能不能按本文当作收费限制。需求变更先写入[统一需求](requirements.md)。

## 是否需要授权

只有决定商业分发后，才评估 `User → Organization → Plan → Entitlement → FeatureGate`。项目打开、保存和已有数据读取不因商业服务故障被锁住。能力目录记录稳定 ID、依赖、引入版本和离线策略；界面禁用不代替接受与输出边界检查。

套餐、定价、30 天离线期限及高级功能划分都是早期候选，未获产品决定。现有离线流程不依赖它们。

## 签名与状态

可评估 Ed25519 离线签名，载荷含授权 ID、主体/组织、能力、签发/生效/过期/离线有效时间、可选设备绑定、keyId、版本和 nonce。定义唯一签名字节表示，拒绝重复字段、未知密钥/算法及歧义数值。客户端只保存验证公钥，签发私钥留服务端。

状态区分未激活、在线有效、离线有效、过期、已撤销。网络错误不能当撤销；有效离线期保留对应能力，超期或撤销后既有数据仍可读写和基础输出。运行任务可保留候选，接受及受限输出重检。

可信服务器时间与单调时间可辅助检查明显回拨，纯离线客户端不能保证防篡改。异常需给恢复办法，不让用户失去项目。

## 配额与实施条件

能力开关与计费配额分离。基础本地编辑不按次扣减；若在线计费，预留/提交/释放必须幂等，失败和取消不重复计费。离线计费、换设备、企业离线签发及退款政策未定前，不发布收费流程。

实施前还需决定密钥轮换、撤销、服务故障、凭据存储、兼容和支持流程；单独设计验收，旧 TC 编号不当作通过记录。
