# 后续范围与实施条件

整理日期：2026-10-26。基准为 0.8.0、HEAD `0bd71c8`，源码按该提交核对。本文保留规划，不承诺排期、套餐或完成状态。当前能力见[功能清单](../guides/feature-catalog.md)，需求和验收统一见[需求与验收](requirements.md)。

## 先确认当前制作流程

现有源码覆盖本地项目、设定图提取/手修、模型、贴附、裁切候选、拼接、制版和输出。继续开发前，应按统一需求检查真实素材和模型的结果、取消/历史一致性、材料依赖、裁片可制作性及打印比例。测试脚本存在不能代替执行记录，失真指标也不能代替实物试样。

## 当前制作主线的工作顺序

| 顺序 | 工作 | 完成依据 |
| --- | --- | --- |
| 1 当前流程核验 | 固定整图／模型样本，检查提取、贴附、裁线、候选接受、历史和输出；采用既有记录时注明构建范围 | FR 对应验收与同一项目的可追溯输出，失败状态完整 |
| 2 纸样交付补全 | 按 PR-01–08 查数量、左右、材料方向、全部应缝边、开口、省道和层次说明 | MC-01–08；现有文字能补足的先明确操作，专用对象列为待实现 |
| 3 制作质量与等待时间 | 用真实材料／部位评估片形、接缝与试样；测量大项目计算、保存和撤销的耗时 | 实物记录和同输入性能记录；不以放宽几何阈值或任务时限代替优化 |
| 4 有证据的编辑能力补充 | 再决定内部工艺线／省道对象、实例装配表、层次关系及独立方向标记的设计范围 | 可重放的缺口样本、数据兼容方案和对应验收；当前不宣称已实现 |

当前版本已有[专项流程验收说明](../../tests/reported-functional-acceptance-contract.md)，但大模型等待时间、工艺信息完整性及实物适用性仍需按各自范围核对。制作主线优先于可选服务；不因未来 AI、账号或云方案阻塞本地纸样制作。

## 保留的方向

| 方向 | 当前边界 | 待实施内容 | 启动条件 |

| [本地 AI](local-ai.md) | 有配置、列模型、技能/MCP 管理及本机桥；无内置对话执行器和 ONNX 管线 | 分割、语义分类、关键点、模型制品与评估数据 | 明确任务、合法模型/样本、基线和回退路径 |

| [账号与授权](licensing.md) | 无账号、订阅、商业令牌或收费门禁 | 能力授权、签名/离线状态、配额 | 另行决定是否商业化，不限制现有离线项目 |

| 多视图重建 | 传统提取和规则分类不能唯一恢复不可见区域 | 相机/姿态、跨视图对应、形状候选和审阅 | 定义可恢复范围、输入、人工回退与误差 |
| 模板市场、机器控制、其他平台 | 有本地模板交换和 Windows 发布流程 | 分发/许可、设备协议、macOS/Linux 构建验收 | 每项独立评审，不由文件格式推导为已支持 |

## 实施前需要补充

记录用户场景、输入输出、失败/取消行为、兼容策略、可重复素材和实际资源预算。性能目标在采集基线和确认硬件前只作候选。联网或模型下载需说明哪些数据离开本机；遥测许可不等于训练许可。

早期 I8/I9、TC 和 ADR 编号只作历史线索，不表示现行任务或验收已完成。未落地方案留在规划；已实现的部分由功能清单与设计文档维护。
