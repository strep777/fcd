# 一套可用于制作的版片应交付什么

适用基准：0.8.0，`0bd71c8`。本文把参考图中的电子打版效果转成可检查的纸样要求，并说明当前软件能保存、能输出和仍需人工补充的内容。对应[制作需求 PR-01–08](../planning/requirements.md)及[交付验收](../planning/acceptance-matrix.md)。

电子打版的交付物是一组能按尺寸裁剪、按对应关系装配的平面版片。三维上看见颜色、二维上看见摊平轮廓，只完成其中一部分。交付还应让制作者知道每片属于哪个部位、裁几份、用何种材料、哪面朝外、毛向如何、哪段边缝到哪里。

## 先确定打哪一层

| 对象 | 这套纸样要解决的问题 | 当前项目的边界 |
| --- | --- | --- |
| 穿戴者身体／DTD | 提供真实尺寸、比例和姿态依据 | 参数生成的人体基体，不等于扫描结果或成衣纸样 |
| 填充后的外表面 | 让衣身包覆预期体积，并保留领口、袖口和踝口 | padded 模式生成五开口衣身；没有由此自动生成独立内胆和外覆两套纸样 |
| 填充内胆／衬里 | 支承、固定或容纳填充，定义连接与开合 | 可分别准备模型和版片；缺少专用层次对象、层间对应及自动厚度补偿 |
| 外覆毛皮 | 在外表面表达色块、毛长、毛向与结构缝 | 当前主要制作主线；材料属性与实际用料仍需确认 |
| 头、手爪、脚、尾及附件 | 各自的包覆面、连接口和制作工艺 | 需分别验证对应模型和纸样；衣身通过不能替代这些部位的验收 |

R07、R09、R10 表达填充外形和内胆意图，R01、R08、R11 表达角色外观。雕刻毛束、爪、硬质眼件不能无条件转成毛皮版片。相关原图见[图片索引](../design/reference-image-analysis.md)。

## 每张纸样的内容

| 内容 | 制作者要读懂什么 | 当前数据与输出 |
| --- | --- | --- |
| 身份 | 版本、片名、部位和实例，能找到对应三维区域 | 有项目修订、片 ID、片名和实例号；部位／左右建议写进片名或文字标注 |
| 净样与裁剪线 | 按哪条线缝，按哪条线裁 | 两条轮廓及孔洞分别生成；SVG／DXF 分层，PDF 用虚实线区分 |
| 缝份 | 统一值、逐边例外和零缝份边 | 支持统一及逐边设置；逐边具体含义应在图上或说明中复核 |
| 数量与左右 | 总共裁几份，哪些镜像，材料正反面如何放 | `cutQty` 与 `mirror` 控制实例；纸样没有独立的结构化左右／正反面字段 |
| 材料 | 颜色、材质、必要的毛长和材料版本 | 材料名称与 `materialId` 关联分别存在；只有文字名不等于启用全部材料约束 |
| 方向 | 片相对毛向、布向及允许转角 | 保存毛向和可选布向，但制造图当前只画一个有效方向箭头 |
| 装配 | 每段应缝边的另一侧、起止位置和对位点 | 有接缝边／区间、方向、吃量、公差和配对剪口；无完整实例装配表自动输出 |
| 功能开口 | 哪些边留开，拉链或连接件的位置和止点 | 可借文字及制作备注说明；没有专用拉链、门襟和开合件对象 |
| 省道／内部工艺线 | 省尖、收量、折向、车线或定位线的用途 | 有开放曲面裁线；没有完整独立省道对象和通用内部工艺线对象 |
| 比例与分页 | 按实际大小打印，各页怎样拼合 | 毫米输出、100 mm 尺、页号和定位；打印驱动比例仍需实测 |

字段证据见 [Piece／Seam 契约](../../packages/schema/index.ts)、[输出布局](../../apps/desktop/main/export.ts)、[材料解析](../../packages/manufacturing/material.ts)。这些是现状说明，不是本轮已执行的制作验收。

## 几种线各管什么

净样线是缝合后的成形边界。缝份向外生成裁剪轮廓，裁剪轮廓的孔洞也要按规则处理；不能用把整片放大的方式代替偏移。纸面上按裁剪线裁，沿净样线缝，接缝长度也量净样线。

结构缝用于成形、装配或必要展开；同色区域也可能有结构缝。材料边界表示实际换料，`sewn` 色区参与分片，`detail` 保留为印绘／贴花图案。内部车线、折线和定位线即使画在片内，也不应被误当作外轮廓或孔洞。Seamly2D 把主路径、缝份、剪口和内部路径分开处理，可作为这类语义分离的参照；当前项目尚未具备它的完整内部路径编辑能力。[Seamly 版片操作说明](https://forum.seamly.io/t/preparing-pattern-for-print/9118)

省道是让平面材料收合成形的工艺。R16、R19 的省口可以作为切缝和对应关系的视觉目标，但一个开口形状不能完整说明“沿哪两边缝、从哪端开始、是否剪开、向哪边倒省”。目前应在片名、文字或单独制作说明中补充。不要通过把 `Piece.closed` 设为 false 来表达一条可直接输出的内部车线；开放纸样轮廓会触发制造检查。

## 数量、镜像与材料方向

普通输出中，`cutQty` 是总份数。开启 `mirror` 后，第 2、4、6……份镜像：数量 2 表示原片、镜像各一份；数量 4 表示各两份；数量 1 不会自动增加镜像副本。排料输出按实际实例记录处理，仍应核对实例总数与方向。

“镜像”本身没有说明哪份属于角色左侧，也没有说明描到毛皮背面时的朝向。来源或模型已经分了左右，不等于每张导出纸样都自动标好左右。采用不对称角色花纹时，要分别检查两侧，不以对称复制覆盖另一侧的独有图案。

当前输出优先使用毛向；只有材料要求布向且不要求毛向、并已填写布向时，才以布向作为有效箭头。材料同时需要两种方向时，应补充文字说明并复核，不能把图上的一支箭头理解成两种方向均已独立标出。旋转和镜像后箭头须随实际实例变换，排料不能为了省料擅自逆毛。

## 把接缝检查到每一实例

当前 `Seam` 能记录两条边或区间、方向、吃量和公差。软件检查已有接缝的有效性、长度残差和已生成剪口的一致性，但没有自动证明所有应缝边都已建立配对。没有报接缝错误时，仍可能有未登记的边。

接缝引用版片 ID，不引用第几份裁剪实例。若一片裁多份、包含镜像或与其他层连接，需要人工注明实例对应。制造图会输出已生成的剪口及其文字，尚不自动附带完整配对表、缝合方向图或装配顺序。

每套纸样应额外核对：

- 需要缝合的边有明确对象；领口、袖口、踝口和其他保留开口另行说明。
- 配对边的起点、方向、剪口次序及吃量一致；曲线边不能只核对两个端点。
- 省道两边、拉链两侧、尾根或其他部件接口具有可执行说明。
- 多份或镜像实例逐一对应，不能只看共用片名。

文字标注会进入制造图；制作流备注不会自动排到纸上。需要制作者离开软件后仍能看到的信息，应写到片名／文字，或随纸样交付单独说明。当前接缝检查入口见 [seams.ts](../../packages/manufacturing/seams.ts)。

## 以一侧蓝白腿为例

这是操作判断示例，不是已通过的制作样本。

1. 选择填充后需要毛皮包覆的腿面，确认尺寸、膝部／踝口及与躯干连接处。
2. 确定白色区域是换白毛料还是表面细节。前者参与材料裁切；后者保留图案并在制作说明中指定做法。
3. 画具有装配意义的结构缝，检查前后侧覆盖；曲率较大处审阅补缝或省口。
4. 查看二维候选的完整片组，核对原三维位置、材料覆盖、接缝长度和局部失真。三角网格线不能自动被理解为每条都要缝。
5. 接受候选后设置缝份、片名、总数量、镜像和方向。若角色左右不对称，分别处理两侧花纹。
6. 补足实例配对、省道、开口和连接说明，输出并回读，再打印测尺和制作试样。

R03–R05 的长结构缝、片号与方向标记，R12–R14 的整套片组，R15–R19 的编辑与三维二维对应，分别支持这条操作路线中的不同要求。图片没有提供真实模型尺寸，因此不能据图计算接缝误差或指定统一片数。

## 制作效果怎样确认

先用原图、三维表面和独立几何检查确认数据正确，再回读最终 SVG／DXF／PDF。纸样应保留完整实例、轮廓、孔洞、文字和方向，打印后量 100 mm 尺。

试样还要检查能否按标记装配、局部缝位是否可操作、毛向是否符合预期以及穿戴活动是否合适。Matrices 的身体制作教程采用试样修版，再确定花纹、方向和开合安排；这支持本项目将“几何通过”和“实物通过”分别记录。[Making a Fursuit Body](https://pupdates.matrices.net/post/126844191210/making-a-fursuit-body)

双向弯曲表面通常不能在保持所有长度和角度的同时完全摊平，需要在切缝、局部形变和制作方式之间选择。数值阈值通过不等于材料具有同样的伸缩能力，也不能证明当前片数最少。真实小色块可以保留；由网格切割误差产生的碎片不应靠删除原材料来消失。对应算法与检查见[算法链](../design/algorithm-pipeline.md)和[裁切设计](../design/design-boundary-cutting.md)。
