# 兽装电子打版与版片

核对日期：2026-10-26。本文解释制作对象和工艺关系；当前软件操作见[操作指南](user-workflow.md)，功能状态见[功能目录](feature-catalog.md)。

FurryPattern CAD 的目标是把角色设定、真实尺寸和制作方式转成可检查、可修改、按毫米输出的兽装纸样。一个完整结果应说明每片在哪里、用什么材料、毛向朝哪里、与哪条边缝合，以及纸样如何对应三维表面。仅把设定图描成轮廓，或把模型切成没有重叠的 UV 岛，都不足以完成打版。

## 版片是什么

版片是一个具有制作含义的平面形状，可以由纸张承载，也可以作为 CAD 中的毫米几何存在。它通常包括净样轮廓、裁剪轮廓、孔洞、剪口、编号、左右侧、材料和毛向。沿净样线缝合后，多片材料共同形成预期的三维外形。

| 名称 | 本项目采用的含义 | 容易混淆的对象 |
| --- | --- | --- |
| 设定图 | 角色形体、配色和特征的视觉依据 | 未标定的图片不能直接提供真实尺寸 |
| 花纹源区 | 从原图提取或手工描出的二维区域，保存原图来源 | 一个源区不一定是一片布 |
| 表面花纹 | 已贴附到三维面上的颜色／制作区域 | 它可以跨越多个将来的版片 |
| 材料边界 | 两种实际用料的分界 | 阴影、线稿和高光不一定换料 |
| 结构缝 | 为成形、装配、开合或展开设置的缝 | 同一种颜色内部也可能需要结构缝 |
| 省道 | 通过局部收合改变平面与曲面关系的结构 | 不是可以任意填掉的几何缺口 |
| 版片／纸样 | 平面上的制作定义 | 不是原图裁图，也不等于一个三角网格面 |
| 裁片 | 按纸样裁出的材料；界面也用此词指数字纸样 | 文档涉及数据时具体指 `Piece` |
| 净样线／缝合线 | 设计的成形边界 | 不包含额外缝份 |
| 裁剪线 | 加入缝份等工艺余量后的剪裁边界 | 不应代替接缝长度的测量基准 |
| 缝份 | 净样线到裁剪线的额外材料 | 与穿着松量、打印搭接、排料片间距分别设置 |
| 毛向／布纹方向 | 材料铺放与裁剪的方向约束 | 屏幕上的任意旋转不代表可以逆毛排料 |
| 剪口／对位标记 | 两片边界在装配时的对应点 | 不能只凭相邻外观猜配对关系 |
| 打印分页 | 把大纸样分割到纸张，带拼页定位和校验尺 | 不是按布幅节约材料的排料 |

用户提供的[山本教育纸样下载版块](https://www.shanbenjiaoyu.com/forum.php?mod=forumdisplay&fid=22&forumdefstyle=yes)列出了 DXF、PRJ 等服装制版文件及男装、女装、裤装等类别。它说明纸样是可保存、交换、修改的制作资料；本次只阅读公开页面，没有把需登录或付费的附件当成已审阅样本，也没有据此宣称本项目兼容 PRJ 或某个行业 DXF 方言。

## 三个身体对象

1. **穿戴者身体／数字 DTD**：记录穿戴者的尺寸、比例和姿态，是合身的依据。
2. **填充后的制作外表面**：身体外加入臀部、大腿、小腿等填充后，毛皮需要包覆的表面。
3. **角色展示模型**：可能含头毛、爪、角、尾巴和细小雕刻，主要表达角色效果。哪些部分用布、泡沫、硬件或印绘制作，仍需指定。

传统 DTD 是用胶带取得的身体替身；本项目的 DTD 模式是参数生成的数字身体，不表示完成了扫描重建。当前 `padded` 一体填充模式生成衣身，颈口、双袖口和双脚踝口敞开，头、手和脚分开处理。参考图片中带脚掌或角色头部的模型是外观需求证据，不能覆盖当前模式的边界。

WikiFur 将兽装制作分为头、躯体、尾、前掌和后掌，并说明人造毛皮、泡沫、其他材料和填充在不同部位的作用。由此，本项目需要分别保存身体尺寸、填充体积和表面材料，而不能把它们合成一个“整体缩放”参数。[兽装制作](https://zh.wikifur.com/w/index.php?title=%E7%8D%B8%E8%A3%9D%E8%A3%BD%E4%BD%9C&variant=zh-hans)

## 实体制作与软件的对应

```mermaid
flowchart LR
  A[角色设定与尺寸] --> B[身体及填充外形]
  B --> C[材料分区与结构缝]
  C --> D[展开并检查版片]
  D --> E[缝份 毛向 编号 剪口]
  E --> F[排料与实际尺寸打印]
  F --> G[试样 缝制 试穿 修版]
  G --> B
  G --> C
```

| 实体工作 | 软件要提供的帮助 | 仍由制作者判断 |
| --- | --- | --- |
| 量体、确认姿态与穿着需求 | 毫米输入、模型尺寸、测量拟合 | 测量是否可信、活动松量是否合适 |
| 做头基底、身体或填充内胆 | 导入／生成制作表面，区分身体与衣身 | 内胆工艺、材料厚度、连接方法 |
| 包覆取版并画颜色线与缝 | 三维花纹、曲面裁线、对称与局部编辑 | 缝放在哪里便于裁剪和缝制 |
| 剪开并摊平 | 展开候选、失真报告、省道与必要补缝 | 额外接缝能否接受，是否改用其他工艺 |
| 给纸样加标记 | 片名、材料、毛向、剪口、接缝配对、缝份 | 毛长、用料、裁剪数量与左右翻转 |
| 描到毛皮背面、裁剪缝合 | 按材料排料，输出真实尺寸纸样 | 实际布幅、瑕疵、伸缩及缝制操作 |
| 试装、梳毛、修剪与修版 | 保存版本，追溯修改，重新生成输出 | 真实穿着效果及最终制作验收 |

## 花纹怎样变成制作边界

同一块腹部白色可以跨过前中缝，因装配需要分成左右两片；一块蓝色腿片也可能因曲率需要省道。反过来，眼睛高光、阴影或渐变未必需要独立布片。当前花纹的 `fabrication` 分为 `sewn` 和 `detail`：前者参与缝制材料分区，后者保留为印绘／贴花细节，不自动产生独立缝制版片。`detail` 也不等于已经实现打印机、绣花机或喷绘设备的生产接口。

材料区域必须保留真实孔洞和相邻关系；不得通过删掉小区域、把不同颜色并成一色或用完整模型盖住漏片来制造“成功”。算法失败时应留下原项目和明确原因，让制作者改裁线、改制作范围或修正输入。

## 可制作结果的判断顺序

先确认身体和填充尺寸，再确认材料与花纹位置；随后检查结构缝、省道、每片轮廓和成对缝边。二维片形必须能回到三维对应位置，输出尺寸必须独立于屏幕缩放。打印后测量 100 mm 校验尺，再用试样确认合身与缝制可行性。

算法失真阈值属于计算结果的准入条件，不是毛皮的材料性能保证。参考图中的流畅裁线、少片布局和成品照片是需求依据；任何一个截图都不能证明隐藏面覆盖、真实接缝长度或穿着活动量已经合格。

每片和整套纸样应提供哪些标记、怎样确认数量／镜像、哪些工艺当前需要人工说明，见[版片交付规格](pattern-delivery.md)。它把上述概念落实到当前软件的数据、输出和制作核对步骤。
