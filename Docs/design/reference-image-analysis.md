## 共同目标与需要单独证明的事项

图示目标现对应到制作交付需求：R01、R07–R11 对应制作对象和层次 PR-01；R03–R05、R13–R14 的片号、箭头和连续缝对应 PR-02–05；R15–R19 的裁线、省口和三维二维联动对应 PR-04–07；R06、R12 的成套纸样交付对应 PR-08。19 张图仍分别保留上表解释，不能由某一张替代其余部位或工艺。具体检查步骤见[版片交付规格](../guides/pattern-delivery.md)。

参考图支持以下需求：在真实尺寸上制作填充衣身；让结构缝围绕服装装配组织；在模型与平面片之间定位；保留材料、左右、毛向、接缝和省道信息；把纸样按实际尺寸交给制作者。

图片无法证明接缝长度误差、隐藏面覆盖率、算法用时、最少片数、所有花纹的提取精度，也不能证明打印文件与实物一致。需求验收应使用源文件、几何数值、导出回读和试样记录，详见[需求文档](../planning/requirements.md)与[验收矩阵](../planning/acceptance-matrix.md)。

当前实现已经具有源图编辑、模型管理、表面贴附、裁线、展开候选、拼接预览和制造输出的代码路径。流畅的服装结构缝优化、材料实测变形及完整实物试穿，仍需分开验收，不能由“生成了候选”推定完成。
