# 本地推理与模型治理规划

状态：未落地方案；整理日期 2026-10-26。当前助手完成配置、模型清单、MCP 连接测试及可选本机桥，见[功能 F29](../guides/feature-catalog.md)。传统原图处理和规则分类不等于 ONNX 推理。验收由[统一需求](requirements.md)管理，不承诺本轮开发或模型质量。

## 计划的任务

评估本地分割、部位语义分类、关键点、比例估计和投影辅助。各任务单独定义输入、输出和不确定性，预测先生成候选。保留传统提取和手工修正；缺模型、资源不足或后端故障时回退，不损坏既有数据。

内置对话代理和外部工具调用是独立需求，不能由模型配置推导为已经具备。若要从当前 MCP 列工具发展到执行，另定义调用、确认、取消和写入规则。

## 模型制品

计划的 manifest 记录 ID/版本、SHA-256、大小、任务、输入输出名称/形状/类型、颜色空间、归一化、缩放/补边、类别表、opset、运行时/后端约束、许可、训练数据授权概要和质量报告。推理绑定 manifest，不只保存 ONNX 文件名。

下载先写临时文件，校验来源和完整性后原子入库；不自动执行附带脚本。升级不重跑旧项目，用户重新识别才生成候选。结果记录模型/运行时/后端、输入哈希和预处理变换，支持重放及偏差定位。

## 推理与取消

管线为原图代理、固定预处理、本地推理、mask/置信信息、移除补边、还原原图坐标，再进入轮廓与审阅流程。logits 不直接当概率；阈值和校准写入 manifest。unknown、低置信和域外输入需人工入口。

后台任务受资源预算约束，取消在阶段间及可中断计算中检查，过期响应不写入。回退记录实际后端；同构建/后端检查确定性，跨后端比较误差，浮点差异不能自动覆盖已存路径。

## 数据与评估待决

样本包含原图、mask、物种、部位、花纹类型、关键点、授权依据和人工修订版本。按角色/作者分组划分训练、验证和测试，避免同角色不同视图泄漏。锁定测试集后不用它调参。

早期 200 张授权图、各主类 20 个样本、1024 分辨率、macro IoU 0.80、2 px 容差边界 F1 0.85 都是待复核目标，目前没有据此交付的模型或评估证据。实施前需补小类、细节、遮挡、画风及域外指标，并与传统/手工流程比较。

云推理、训练贡献和遥测分别由用户选择。贡献记录授权范围、版本和撤回方式；已训练模型的撤回政策另定，不承诺自动反训练。
